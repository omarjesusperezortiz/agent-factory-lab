Research lab · AI coding agents

A software factory run by agents.

How do you turn single AI coding sessions into a line that ships tickets every day, and catches its own mistakes? Follow one ticket through it.

scroll to follow the ticket
01 · The line

Every ticket goes through the same five stations.

Each station is one agent with one job and only the files it needs. The order lives in plain code, not in a model's memory.

  • scout · reads the ticket and the repo
  • spec · writes down the intent
  • worker · writes the code
  • tester · runs it for real
  • reviewer · a different model judges
02 · The loop

The tester says no. That's the system working.

The ticket goes back to the worker with the failure attached, then tries again. Loops are bounded: after three rounds it goes to a person instead of spinning.

The reviewer runs on a different model, so the same blind spot doesn't approve its own work.

03 · The ledger
0

Now do that for every ticket, every day.

A ledger in code tracks each one: which station, which attempt, what it cost. Nothing goes missing because nothing depends on an agent remembering.
