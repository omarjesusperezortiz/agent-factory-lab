Fable 5.2 as the lead agent: nine rules from Anthropic for using it well

Fable 5.2 is Anthropic's strongest model, 20% cheaper than 5.1, but still twice Opus 5.5 per token, and it burns plan limits fast. AI LABS boiled Anthropic's launch guide, Lydia Hallie's Claude Code talk and Addy Osmani's model guide down to nine rules. Most are about setup, not prompting: start on Opus, give Fable a checkable finish line, and use it as the lead that plans and judges while cheaper models build. Running example: a job board app, the project in the video's own CLAUDE.md.

What this means for us

RuleWhat to do in the factory
1. Don't start on FableDefault every role to Opus 5.5 on medium. Escalate a task to Opus on high, then to Fable, only when the cheaper run fails its checks. Log each escalation on the Costs view so we learn which task types really need Fable.
2. Define done firstNo issue enters the factory without a list of pass/fail checks (tests, commands, screenshots to compare). "Make it good" is not a spec. Set the bar high: Fable works until it meets it.
Fresh-session reviewBuild with Opus on medium; review with a separate Fable agent that never saw the build. Record its findings in Evals, and don't let a human "it's fine" overwrite a finding that has a failing test behind it.
3. Three Fable jobsRoute only big multi-part jobs (rewrites, architecture), 3D/game work and the hardest bugs to Fable. On those, Fable on high matched Opus on max for about half the cost per task.
4. Fable leads, others buildThe orchestrator is a Fable lead on high that only plans, splits and judges. Put the routing table in CLAUDE.md: simple and clear → Sonnet, needs thinking → Opus 5.5, search and logs → Haiku. Also state what a sub-agent costs and "start one only for work that can run in parallel": in Anthropic's test that cut sub-agents started by about half. Skip the lead for small features (1.7× the cost of Opus alone).
5. Lead on highLong unattended runs use high effort. On medium, Anthropic's "don't stop while you still owe work" block halves unfinished runs but only fixes the "want me to continue?" stop, not the "here's what's left" stop. Never go past high by default.
6. Run without askingList every place the lead may work (repos, folders, the staging site) in CLAUDE.md. Steps that can be undone go ahead; steps that can't go to the Human inbox. Approve with the exact scope ("yes, run this migration on staging") so the same question doesn't come back.
7. Report for the absent readerLead's final report: most important points first, plain words, screenshots and test results attached, every small change listed. Render it as a page the Human inbox can open.
8–9. Tidy setup, switch cleanlyRun /prompt-audit on CLAUDE.md and skills; turn "NEVER X" into "ask before X". Don't switch models mid-task: the prompt cache belongs to the model that read it, and Fable's thinking doesn't carry over. /compact or start fresh, then switch.
